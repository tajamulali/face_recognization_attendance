# Face Recognition Attendance System

## 📌 Overview
The **Face Recognition Attendance System** is an AI-powered smart attendance solution built using **Python, OpenCV, and MySQL**. It leverages **machine learning algorithms** for real-time face detection and recognition, providing an automated and secure way to track attendance.

## 🚀 Features
- **Real-time Face Detection & Recognition** using **Haar Cascade Frontal Face Algorithm** and **Local Binary Patterns Histograms (LBPH)**.
- **Live Camera Feed Processing** with OpenCV.
- **Student & Admin Management** via a user-friendly **Tkinter GUI**.
- **Automated Attendance Logging** integrated with **MySQL database**.
- **Training Module** to dynamically recognize new faces.
- **CSV Export & Report Generation** for easy tracking.
- **AI Chatbot (GigiBot)** for troubleshooting and automated responses.
- **Secure Data Storage & Access Control**.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **GUI Framework:** Tkinter
- **Face Recognition:** OpenCV
- **Face Detection Algorithm:** Haar Cascade Frontal Face
- **Machine Learning Algorithm:** Local Binary Patterns Histograms (LBPH)
- **Database:** MySQL
- **File Handling:** CSV for attendance export

## 📸 How It Works
1. **Face Registration:**
   - Users register their faces using the system.
   - The model stores facial features for recognition.

2. **Attendance Marking:**
   - The system scans faces using the camera.
   - Recognized faces are marked present in the database.

3. **Report & Export:**
   - Attendance records are stored and can be exported as CSV files.

## 🧩 Modules
- **Student Management:** Add, update, and manage student details.

- **Training Module:** Improves recognition by training new faces.
- **Attendance Tracking:** Automates attendance logging.
